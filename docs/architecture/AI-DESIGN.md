# AI design and authority

A bounded LangGraph investigator observes original browser/document evidence, records cited hypotheses and submits typed proposals. Separate policy, private-copy simulation and final-state verification precede exact-version review and receipted actions. PostgreSQL coordinates leased browser workers; fixture worlds and checkpoints still use same-node files.

The private investigator uses the official async Anthropic SDK with bounded typed tool requests, context/token/round limits and explicit live selection. The guided public app instead uses the existing deterministic diagnostic planner through a LangGraph workflow. Its working calculations do not establish model reasoning quality.

Browser pixels/accessibility and source documents enter bounded private observations; cited hypotheses precede proposal validation and private-copy simulation. The action broker, review and evaluator remain outside model tool authority.

Provider transport tests and known synthetic cases test engineering behavior. Live-model quality, unseen generalization and actual user benefit remain unmeasured. [Agent implementation](AGENT-WORKBENCH.md) · [Original design history](../project/history/FOUNDATION-AI-DESIGN.md).
