# Portfolio evidence and demo

Current runnable demonstrations are CLI synthetic worlds: assess without writes, execute explicit sandbox actions with lost acknowledgement/reconciliation, and abstain on unknown delivery. Generated report.json records source state, plan, graph activity, simulation, actions and final verification. All remain ignored local artifacts.

Intended visible demo: case arrives; evidence is inspected across real sandbox app pages and a scanned document; agent proposes a plan; operator reviews exact changes; execution hits a timeout after a write; receipt becomes uncertain; agent reconciles instead of duplicating it; independent final state passes and the replay explains what changed.

Intended product pages: home/task queue, case detail, evidence/document viewer, plan/review, execution/recovery timeline, run replay, policy/connector settings and evaluation explorer. Product/UI and this browser journey are not implemented yet.

Release evidence should include live traces, frozen evaluation reports, latency/cost comparisons, actual user feedback and a tradeoff write-up. No fabricated model score, novelty, customer savings or academic endorsement. Personal portfolio/ remains empty and separate.
