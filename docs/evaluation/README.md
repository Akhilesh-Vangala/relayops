# Evaluation and engineering evidence

## What is measured

| Scope | Implemented checks |
| --- | --- |
| Native regression suite | 65 cases;3 PostgreSQL-only skips without a test database. CI provides the relevant integration services. |
| Public browser journey | Actual investigation, evidence/verification, version-bound review, lost-acknowledgment execution/reconciliation, JSON download, reload/history, mobile layout and video metadata. |
| Private integration | Model transport, citation/recovery/receipt checks and16browser checks; actual Compose/Kind API restart and worker execution. |
| Known synthetic regression | 12 scripted assessments with original source state unchanged. |
| Live model quality | Not measured. Scripted providers and fixed diagnostics are not model-accuracy evidence. |

Local and container executions repeat the same distinct cases; do not add their counts as unique tests. The required CI artifacts are the source for those counts.

## Independent acceptance boundary

The final-state evaluator compares business outcomes, source preservation, held amount/claim/reservation quantities and receipt duplication. Its implementation is separate from the planner/action policy, while sharing the declared synthetic business contract. Unknown acknowledgments require reconciliation; cross-request public stages reconstruct fresh fixtures rather than proving durable external exactly-once effects.

## Uncompleted evaluation gates

Frozen unseen task/data families, live model comparisons and repeats, representative real integrations, safety challenges, actual operator feedback, observed costs/latency, and monitored persistent cloud/load/restore evidence remain release work. No live quality, customer impact or causal inference result is inferred from deterministic success.
