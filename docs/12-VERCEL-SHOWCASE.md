# Vercel engineering showcase

## Public surface

[relayops-two.vercel.app](https://relayops-two.vercel.app) runs the real RelayOps FastAPI interface on Vercel's Python 3.12 runtime. Visitors can inspect the case catalog, synthetic source records, implemented architecture, investigation summary and the recorded isolated execution.

The deployment is intentionally read only. `RELAY_PUBLIC_SHOWCASE=1` permits public `GET` requests and rejects every other HTTP method with `405 Public showcase is read-only`. The Vercel entrypoint also forces live model execution off. No provider credential is uploaded.

## Why actions are disabled

The local operator workflow relies on persistent SQLite state, background tasks and browser execution. Vercel Functions have request-scoped execution and an ephemeral filesystem, so exposing those actions here would produce misleading durability and recovery behavior. The recorded journey links to evidence generated by the actual isolated application while the cloud surface remains safe to explore.

This deployment proves that the application builds and serves on Vercel, its public navigation works, and the server enforces the read-only boundary. It does not prove live model quality, durable cloud workers, distributed recovery, production connectors, individual authorization or monitored production operation.

## Reproduction and verification

- `app.py` is the Vercel ASGI entrypoint.
- `.python-version` selects Python 3.12; Python 3.11 remains supported locally and in CI.
- `.vercelignore` excludes credentials, local environments, generated artifacts and test state from uploads.
- `vercel.json` bounds the function duration and deployment bundle.
- `tests/test_web.py` checks remote reads and server-side write rejection through the ASGI application.

The first cloud build completed in Vercel `iad1`. External HTTP and Chromium checks verified the overview, `/showcase`, the recorded image, security boundary and absence of browser console errors. The canonical URL is smoke-tested again after each intentional production promotion.
